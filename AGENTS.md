# Repository guidance

This checkout is the source of the Pi Delegate skill and distributable plugin.

- Edit the root `SKILL.md`, `references/`, and `scripts/`. Plugin copies under
  `dist/` are generated by `scripts/package_plugin.py`; do not edit them.
- Keep the worker backend in Pi RPC mode and Python standard-library-only.
- Preserve the standalone symlink installer and host-neutral helper paths.
- After helper, installer, or packaging changes, run
  `python3 -m unittest discover -s tests -v`. The suite uses fake Pi and makes
  no model calls. Run real Pi smoke checks only when authorized.
- Follow the skill's Herdr pane lifecycle. Never commit `.pi/`, local `.agents/`
  configuration, provider settings, or generated plugin builds.
- Record verified outcomes and outstanding work in `PLAN.md`.
